# Quickstart: 019 法的ページ・通報フォーム 動作確認

## 環境変数の設定

`negotole/.env.local` に以下を追加する（プレースホルダー URL で OK）:

```
NEXT_PUBLIC_CONTACT_FORM_URL=https://forms.gle/PLACEHOLDER_CONTACT
NEXT_PUBLIC_REPORT_FORM_URL=https://docs.google.com/forms/d/PLACEHOLDER/viewform
```

## 確認シナリオ

### シナリオ 1: 利用規約ページ

1. `http://localhost:3000/terms` にアクセス
2. **確認**: ページが表示される（ステータス 200）
3. **確認**: 以下のセクションが存在する
   - 禁止事項
   - 投稿削除権限
   - 著作権の扱い
   - ログ保持ポリシー
4. **確認**: 最終更新日が明記されている
5. **確認**: ログイン不要でアクセスできる

### シナリオ 2: プライバシーポリシーページ

1. `http://localhost:3000/privacy` にアクセス
2. **確認**: ページが表示される
3. **確認**: 以下のセクションが存在する
   - 収集する個人情報
   - 利用目的
   - 第三者提供
   - ログ保持期間（3年と明記）
   - 外部サービス一覧（Google OAuth、Upstash Redis、Neon）
4. **確認**: 問い合わせ先が明記されている

### シナリオ 3: お問い合わせページ

1. `http://localhost:3000/contact` にアクセス
2. **確認**: ページが表示される
3. **確認**: Google フォームへの外部リンクが存在する
4. **確認**: リンクが新しいタブで開く（`target="_blank"`）

### シナリオ 4: フッターリンク

1. トップページ（`http://localhost:3000/`）を表示
2. **確認**: ページ下部にフッターが表示される
3. **確認**: 「利用規約」「プライバシーポリシー」「お問い合わせ」のリンクがある
4. 各リンクをクリックして対応ページに遷移することを確認

### シナリオ 5: 通報ボタン（ログイン状態）

1. ログインしてトップページを表示
2. **確認**: 各投稿カードに通報ボタン（またはアイコン）が表示される
3. 通報ボタンをクリック
4. **確認**: 新しいタブで Google フォームが開く
5. **確認**: URL に投稿 ID が含まれている（例: `?entry.XXXXXXX=postId:42`）

### シナリオ 6: 通報ボタン（非ログイン状態）

1. ログアウトした状態でトップページを表示
2. **確認**: 投稿カードに通報ボタンが**表示されない**

## ビルド確認

```bash
cd negotole
pnpm build
```

静的ページとして最適化されることを確認（`/terms`、`/privacy`、`/contact` が Static になること）。
