# UI Contracts: レスポンシブコンポーネント動作仕様

## Header コンポーネント

**対象**: `negotole/src/components/Header.tsx`

### 動作仕様

| 画面幅 | レイアウト | ナビゲーション要素 |
|--------|-----------|-----------------|
| < 640px（モバイル） | 全要素を1行に収める。コンパクトスタイル適用 | ロゴ・ポイントバッジ・「投稿する」・「ログアウト」（または「Google でログイン」）が横スクロールなしで表示 |
| ≥ 640px（sm:）以上 | 既存スタイルを維持 | 同上（余裕のある間隔） |

### 受け入れ条件

- 画面幅 375px において、ヘッダー内コンテンツが viewport 幅を超えない
- すべてのボタン・リンクのタップ領域が 44×44px 以上（`min-h-[44px]` または既存の padding で保証）
- ログイン状態・未ログイン状態の両方で崩れが発生しない

## PostForm コンポーネント

**対象**: `negotole/src/components/PostForm.tsx`

### 動作仕様

| 要素 | モバイル要件 |
|------|------------|
| `<textarea>` | `font-size: 16px` 以上。iOS で入力時にページズームが発生しないこと |
| 送信ボタン | 画面幅に関わらず `w-full` またはタップ可能な十分な幅を確保 |
| 時間選択ボタン群 | `flex-wrap` により折り返し表示 |

### 受け入れ条件

- iOS Safari でテキストエリアをタップしてもページがズームしない（font-size ≥ 16px）
- キーボード表示時にフォームの送信ボタンが操作できる

## Admin Layout

**対象**: `negotole/src/app/admin/layout.tsx`

### 動作仕様

| 画面幅 | パディング |
|--------|----------|
| < 640px | `p-4`（16px 四辺） |
| ≥ 640px | `p-6`（24px 四辺）— 既存スタイル維持 |

### 受け入れ条件

- 画面幅 375px でコンテンツが適切なマージンで表示される

---

## Admin Campaigns テーブル

**対象**: `negotole/src/app/admin/campaigns/page.tsx`

### 動作仕様

| 画面幅 | テーブル表示 |
|--------|------------|
| 全幅 | テーブルを `overflow-x-auto` ラッパーで囲み、幅が不足する場合に横スクロールで表示 |

### 受け入れ条件

- 画面幅 375px でテーブルが横スクロール可能な状態で表示される（コンテンツが切り捨てられない）
- 「編集」リンクのタップ領域が十分な大きさ（44px 以上）
