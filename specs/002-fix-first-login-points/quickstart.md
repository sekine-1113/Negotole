# Quickstart: 初回ログインポイント付与バグ修正 & キャンペーン恒久ポイント

## 前提

- `pnpm dev` が起動済み（`http://localhost:3000`）
- `.env.local` に DB・Auth 環境変数が設定済み
- DB マイグレーション適用済み（`user.role` 列と `campaign` テーブルが存在する）

---

## シナリオ 1: バグ修正の確認（P1）

### 1-1. 新規ユーザーのデイリーポイント付与

1. シークレットウィンドウで `http://localhost:3000` を開く
2. ヘッダーの「ログイン」をクリックし、Google アカウントでサインイン
3. ヘッダーに **10pt** が表示されることを確認
4. ログアウト → 同日に再ログイン → **10pt のまま**（重複付与なし）を確認

### 1-2. 翌日のデイリーポイント付与

> ローカルで確認する場合は DB の `user_point` テーブルの `expires_at` を昨日の日付に書き換えてテスト

1. `user_point` テーブルの該当レコードの `expires_at` を過去日時に更新
2. 再ログイン → 新たに 10pt 付与されることを確認

---

## シナリオ 2: 管理者ロールの設定

### 2-1. 自分のアカウントを管理者にする

```bash
# DB に直接接続して role を更新
set -a && source .env.local && set +a
# psql で実行:
UPDATE "app_user" SET role = 'admin' WHERE email = 'your@email.com';
```

または Neon コンソールから SQL を実行する。

### 2-2. 管理者ページへのアクセス確認

1. `http://localhost:3000/admin/campaigns` にアクセス
2. 管理者でログイン → キャンペーン一覧が表示されることを確認
3. 一般ユーザーでアクセス → `/` にリダイレクトされることを確認

---

## シナリオ 3: キャンペーン管理（P2）

### 3-1. キャンペーンの新規作成

1. `http://localhost:3000/admin/campaigns/new` にアクセス
2. フォームに入力:
   - キャンペーン名: `新規登録キャンペーン2026`
   - 開始日時: 今日以前の日時
   - 終了日時: 明日以降の日時
   - 付与ポイント: `100`
3. 保存 → 一覧に表示されることを確認

### 3-2. 重複キャンペーンの防止

1. アクティブなキャンペーンが存在する状態で `/admin/campaigns/new` から新規作成を試みる
2. **エラーメッセージ**「既にアクティブなキャンペーンが存在します」が表示されることを確認

---

## シナリオ 4: キャンペーン期間中の初回ログイン（P2）

1. アクティブなキャンペーンが存在する状態で
2. **まだ一度もログインしていない** Google アカウントでサインイン
3. ヘッダーに **110pt**（デイリー 10pt ＋ キャンペーン恒久 100pt）が表示されることを確認

### 4-1. 既存ユーザーはキャンペーン対象外

1. キャンペーン期間中に **既にアカウントがある** Google アカウントでログイン
2. ヘッダーに **10pt**（デイリーのみ、キャンペーンボーナスなし）が表示されることを確認

### 4-2. キャンペーン期間外は対象外

1. キャンペーンを削除（または終了日時を過去日時に変更）した状態で
2. 新規 Google アカウントでサインイン
3. ヘッダーに **10pt**（キャンペーンボーナスなし）が表示されることを確認

---

## 動作確認チェックリスト

- [ ] 新規ユーザーのログインで 10pt 付与される
- [ ] 同日再ログインで重複付与されない
- [ ] 管理者以外が `/admin/campaigns` にアクセスすると `/` にリダイレクトされる
- [ ] キャンペーン CRUD が正常に動作する（作成・編集・削除）
- [ ] 重複アクティブキャンペーン作成時に 409 エラーが返る
- [ ] キャンペーン期間中の新規ユーザーに 110pt 付与される
- [ ] 既存ユーザーはキャンペーンボーナスを受け取らない
- [ ] `pnpm test` が通る
- [ ] `pnpm build` が通る
