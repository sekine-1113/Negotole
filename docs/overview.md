# Negotole - アプリ仕様書

## アプリ概要

**Negotole** は「時間限定投稿 SNS」。投稿は一定時間後に自動的に非表示となり、いいね・コメント・フォローといった継続的な関係性を生む機能は一切持たない。ユーザーは「今この瞬間」の投稿と一期一会で出会う体験を提供する。

---

## コアコンセプト

- 投稿には有効期限がある（投稿者が選択した時間で `hidden_at` を設定。超えるとタイムラインから消える）
- タイムラインの投稿は**完全匿名**。投稿者の名前・アカウント情報は一切表示しない
- いいね・コメント・フォロー・DM は**実装しない**
- ユーザー間に関係性（フォロー/フォロワー）は存在しない
- タイムラインの閲覧はログイン不要。投稿にはログインが必要
- タイムラインは全ユーザーの有効投稿を時系列で表示する（フィルタなし）

---

## 機能要件

| 機能 | 詳細 |
|---|---|
| タイムライン閲覧 | ログイン不要。全ユーザーの `hidden_at > NOW()` な投稿を新着順に表示 |
| ユーザー登録・ログイン | Google OAuth（NextAuth.js を使用） |
| 投稿作成 | ログイン必須。テキスト（最大 255 文字）と表示制限時間を選択し、ポイントを消費して投稿 |
| 表示制限時間の選択 | 投稿者が投稿時に制限時間を選択する（選択肢は設計時に決定） |
| 投稿の自動非表示 | `hidden_at > NOW()` を超えた投稿はタイムラインに表示しない |
| ポイント管理 | デイリーポイント（当日限定 10pt）の付与・消費。恒久ポイントも将来対応 |
| 論理削除 | 投稿・ユーザーとも `deleted_at` による論理削除。物理削除は行わない |

### 禁止機能（実装しないもの）

- いいね / リアクション
- コメント / リプライ
- フォロー / フォロワー
- DM（ダイレクトメッセージ）
- 投稿の拡散・シェア機能

## データモデル概要

詳細なスキーマは `docs/database.md` を参照。

### 各テーブルの役割

| テーブル | 役割 |
|---|---|
| `user` | ユーザー基本情報。`name`（表示名）と `birth_year` を持つ |
| `user_point` | ポイント履歴。`get_point` が正なら付与、負なら消費を表す |
| `post` | 投稿本文（255文字以内）と `hidden_at`（非表示になる時刻）を持つ |

### 共通カラム

すべてのテーブルに `created_at`・`updated_at`・`deleted_at` を持つ（論理削除対応）。

### `post.hidden_at` の扱い

- 投稿作成時に `created_at + ユーザー選択の制限時間` で計算してセットする
- タイムライン取得クエリは `WHERE hidden_at > NOW() AND deleted_at IS NULL` を必ず含める

## ポイントシステム

### ポイントの種類

| 種別 | 内容 |
|---|---|
| デイリーポイント | 毎日 10pt 付与。**当日限定**（翌日に持ち越せない） |
| 恒久ポイント | 将来実装。特殊な操作（キャンペーン・特典等）で付与。期限なし |

### 消費ルール

- 投稿 1 回ごとにポイントを消費する（消費量は設計時に決定）
- ポイントが不足している場合は投稿不可にする
- デイリーポイントを優先消費し、不足分を恒久ポイントで補う（優先順位 TBD）

### ポイント残高の計算

`user_point` テーブルの `get_point` を `user_id` でグループ集計した合計値が残高となる。  
デイリーポイントと恒久ポイントを区別するカラムの追加が必要（設計時に `user_point` テーブルを拡張する）。

## ユーザーフロー

### 閲覧のみ（ログイン不要）

1. サイトにアクセス
2. タイムラインで全ユーザーの有効期限内投稿を閲覧

### 投稿する（ログイン必要）

1. Google アカウントでログイン
2. 初回ログイン時はユーザーレコードを作成し、デイリーポイントを付与
3. 投稿画面でテキストを入力（255 文字以内）+ 表示制限時間を選択
4. 投稿ボタン押下 → ポイント残高を確認 → 残高あれば投稿保存・ポイント消費
5. 投稿が `hidden_at` を超えると自動的にタイムラインから消える

## UI/UX 方針

- **ミニマルデザイン**: 余計な UI 要素を置かない。いいねボタン等は存在しない
- **完全匿名タイムライン**: 投稿カードに投稿者情報は一切表示しない
- **タイムライン中心**: 画面の主役は投稿一覧。ユーザープロフィールページは持たない
- **残り時間の表示**: 各投稿に `hidden_at` までの残り時間を表示する（例: 「あと 3 時間」）
- **ポイント残量表示**: ログイン時はヘッダー等に現在の残ポイントを表示する
