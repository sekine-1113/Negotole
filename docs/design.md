# 画面設計

## ページ構成

| パス | ページ名 | 認証 | 説明 |
|---|---|---|---|
| `/` | タイムライン | 不要 | 有効期限内の投稿を新着順に表示 |
| `/post/new` | 投稿フォーム | 必須 | テキスト入力 + 制限時間選択 |

未ログインで `/post/new` にアクセスした場合は Google ログインページへリダイレクトする。

---

## レイアウト

```
┌─────────────────────────────────────┐
│  Header                             │
│  [Negotole]     [残 8pt] [ログイン] │
├─────────────────────────────────────┤
│  (ページごとのコンテンツ)            │
└─────────────────────────────────────┘
```

- ログイン済み: ポイント残量 + ログアウトボタン + 投稿ボタン
- 未ログイン: ログインボタンのみ

---

## 各ページ

### `/` タイムライン

```
┌─────────────────────────────────────┐
│ 投稿本文テキストがここに表示される。 │
│ 最大255文字。         あと 2時間 30分│
├─────────────────────────────────────┤
│ 別の投稿テキスト。         あと 45分 │
├─────────────────────────────────────┤
│           [もっと見る]              │
└─────────────────────────────────────┘
```

- 投稿カードに**投稿者情報は一切表示しない**（完全匿名）
- 投稿カードにいいね・コメント・シェアボタンは**置かない**
- 残り時間は動的に更新する（クライアントサイドのカウントダウン）
- ページネーション: カーソルベース（「もっと見る」ボタン or 無限スクロール）
- 残り時間が少ない投稿（1時間未満など）は視覚的に強調しても良い

### `/post/new` 投稿フォーム

```
┌─────────────────────────────────────┐
│ 今どうしてる？                       │
│ ┌─────────────────────────────────┐ │
│ │ テキスト入力エリア              │ │
│ │                                 │ │
│ └─────────────────────────────────┘ │
│ 0 / 255文字                         │
│                                     │
│ 表示時間:                           │
│ [1時間] [3時間] [6時間] [12時間] [24時間] │
│                                     │
│ 残ポイント: 8pt（投稿に 1pt 消費）   │
│                                     │
│              [投稿する]             │
└─────────────────────────────────────┘
```

- 文字数リアルタイムカウント表示
- 制限時間はボタン選択式（ラジオ的な UI）
- ポイント不足時は「投稿する」ボタンを非活性にしてメッセージを表示

## コンポーネント構成

```
src/
  app/
    layout.tsx          # ルートレイアウト（Header を含む）
    page.tsx            # タイムラインページ
    post/
      new/
        page.tsx        # 投稿フォームページ
  components/
    Header.tsx          # ナビゲーションバー
    Timeline.tsx        # 投稿一覧（PostCard のリスト + ページネーション）
    PostCard.tsx        # 個別投稿カード（本文 + 残り時間のみ。投稿者情報なし）
    PostForm.tsx        # 投稿フォーム（テキスト + 制限時間選択 + 送信）
    PointBadge.tsx      # ポイント残量表示バッジ
    CountdownTimer.tsx  # 残り時間のカウントダウン表示
```

---

## 認証フロー（NextAuth.js）

1. 未ログインユーザーが `/post/new` にアクセス
2. `middleware.ts` でリダイレクト → Google ログイン
3. Google 認証完了 → NextAuth コールバックでユーザーレコードを作成 or 取得
4. デイリーポイントの未付与チェック → 当日未付与なら 10pt 付与
5. セッション確立 → `/post/new` へリダイレクト
